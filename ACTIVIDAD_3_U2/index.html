Bienvenidos al sistema

Este sistema permite registrar reportes de animales que necesitan ser rescatados y consultar los rescates realizados.

¿Cómo funciona el sistema?

  1. El ciudadano reporta un animal que necesita ayuda.
  2. Los voluntarios revisan el reporte y coordinan el rescate.
  3. Se registra la información del rescate realizado.
  4. El animal puede iniciar un proceso de adopción.
